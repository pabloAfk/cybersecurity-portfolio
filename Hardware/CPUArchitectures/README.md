Primeiro, o que é? 

A arquitetura de CPU é o projeto estrutural e o conjunto de regras de um processador, definindo componentes como a 
Unidade Lógica e Aritmética (ULA), a Unidade de Controle e o conjunto de instruções. 
Ela determina como o hardware executa os programas e processa os dados.
